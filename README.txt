KNOT RANDOMIZER

Files:
- index.html — app
- manifest.json — installable web-app metadata
- sw.js — offline cache
- icon.svg — app icon

Use:
1. Put these files on any HTTPS web host.
2. Open the site in Safari on your iPhone.
3. Tap Share → Add to Home Screen.
4. Launch it from the new icon.

The randomizer itself works offline after installation/caching.
Links to AnimatedKnots.com require internet access.
